# Working on Research Compass Starter

Read `README.md`, `PRIVATE-COPY-START-HERE.md`, and
`docs/PRIVATE-COPY-SETUP.md` before setup or maintenance.

This is the public, MIT-licensed source starter. Keep its Site ID unset and its
email addresses and installation URLs as examples. Never copy another owner's
deployment identity, database, credentials, task exports, or private Git history
into this repository. Keep a configured installation in its owner's private
working copy. The legacy desktop SQLite backup helper is not part of this app.

For a requested independent deployment, use the current Sites skill and check
that the required tools are available before registering anything. Create one
owner-private Site with a fresh D1 database; retain and reuse its returned ID and
source access. Configure a neutral copy using the supplied configuration helper,
then bring that source into the new Site's authorized checkout. Do not replace
the app with a default framework starter. Keep credentials in memory/stdin.
Publish only to the newly created owner's Site and verify private access and
persistence before using real work. If Sites access is unavailable, explain the
missing capability; do not substitute a public app or another owner's Site.

For public changes, inspect Git status and fetch the public remote first.
Transfer reviewed changes explicitly; do not merge a private repository's
history. Preserve existing public examples, MIT and third-party notices, and
compatibility with current task/review records. Review source and release ZIPs
for personal data and credential material before publishing.

Run the app tests, configuration tests, TypeScript, and build using the README.
Use only isolated synthetic local data. Never point fixture scripts at an
existing person's deployment. Package clean committed unconfigured source with
`scripts/package-private-copy.py`; record the source commit and checksum.
Keep fresh independent hosting, actual device installation, and unattended
agent checks marked unverified until they have been observed.

Setup and publication do not create agent schedules or authorize email sending.
Optional Windows sync helpers are maintenance scripts requiring the new owner's
own connection. Do not install them or change schedules unless requested.
